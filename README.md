# 🍔 FoodFrenzy – Online Food Ordering System

FoodFrenzy is a web-based online food ordering and management system developed using Java, Spring Boot, Thymeleaf and MySQL.

The application allows users to browse food products, search for products and place orders. It also provides an admin panel to manage products, users and orders.

## ✨ Features

### 👤 User Features

- User Registration and Login
- Browse Food Products
- Search Products
- View Product Details
- Place Orders
- View Order Information

### 👨‍💼 Admin Features

- Admin Login
- Admin Dashboard
- Add Products
- Update Products
- Delete Products
- View Products
- Manage Users
- Manage Orders
- View Sales Information

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/tanvi7654-helo/FoodFrenzy.git
```
### 2. Open the Project

Open the project in Visual Studio Code, IntelliJ IDEA or Eclipse.

### 3. Configure MySQL

Create a MySQL database and update the database username and password in:

```text
src/main/resources/application.properties
```
### 4. Run the Application

Using Maven Wrapper:

For Windows:

```bash
mvnw.cmd spring-boot:run
```
### 5. Open in Browser

After the application starts successfully, open your web browser and visit:

```text
http://localhost:8080
```
